# 프로젝트: 알바몬 온보딩 (탐색구조 Track)

## 적용 범위

- 이 지침은 `albamon-onboarding/` 프로젝트에만 적용한다.
- 잡코리아 콘텐츠LAB의 JAMS 2.0 규칙을 자동으로 가져오지 않는다.

## 디자인 원본

- Figma: https://www.figma.com/design/VZmtSaO9fKCxIDtOq5Tx1x/-탐색구조-Track--handoff?node-id=4389-66018
- 섹션 `261020 다시 수정 중`: 로그인 → STEP 1 지역 선택 → STEP 2 근무기간 → STEP 3 업직종
- 시안이 계속 수정 중이므로 텍스트·상태가 바뀌었는지 Figma에서 다시 확인한 뒤 반영한다.

## 프로젝트 구성

- `index.html`: 화면 구조(로그인, STEP 1~3)
- `style.css`: 토큰, 화면 스타일, 반응형 처리
- `app.js`: 지역 데이터, 선택 규칙, 화면 전환
- `assets/`: Figma에서 내려받은 SVG·이미지
- 순수 HTML/CSS/JavaScript로 구현한다. 기본 폰트는 Pretendard다.

## 화면 기준

- PC에서는 390×844 디자인을 휴대폰 프레임 형태로 보여준다.
- 모바일(`max-width: 520px`)에서는 프레임을 없애고 화면 전체를 쓴다. 목업 상태바와 키보드 이미지는 숨긴다.
- PC와 모바일은 각각 따로 검수한다.

## 상호작용 규칙

- STEP 1: 최대 10곳 선택, 초과 시 토스트. 같은 시·도의 `전체`와 개별 시·군·구는 함께 담지 않는다.
- STEP 2: 처음 선택하면 바로 STEP 3으로 넘어가고, STEP 3에서 돌아오면 선택 상태와 `다음` 버튼을 보여준다.
- STEP 3: `한 달 이내`는 단기 업직종 7개, 그 외는 장기 업직종 10개를 보여준다.
- 온보딩 완료 화면은 시안에 없어 `공고 보기`를 누르면 로그인으로 돌아가 처음부터 다시 체험할 수 있게 한다.

## 작업 규칙

- 기존 텍스트와 시안 의미를 요청 없이 바꾸지 않는다.
- 반복되는 색상과 규격은 CSS 변수로 관리한다.
- 에셋은 Figma에서 받은 파일을 그대로 쓴다. 업직종 선택 아이콘(`job-*-on.svg`)은 Figma 원본 5개와, 시안에 선택 상태가 없는 8개는 기본 아이콘의 색(#C0C7CD)만 #FF6D12로 바꿔 만들었다(원본 5개와 같은 방식).
- HTML 파일을 직접 열어(file://) 확인하므로 CSS mask, fetch처럼 file://에서 막히는 기능은 쓰지 않는다.
