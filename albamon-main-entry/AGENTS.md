## 목적 (사용자 정의 2026-11-17)

- 실시간 추천 알바 피드는 메인 진입점 중 공고 조회·지원 전환이 가장 높지만 메인에서 들어가는 사람이 적다. 이번 메인 개선의 목적은 **피드 진입점 강화**다.
- 근거 데이터는 사용자 노션 문서 '알바몬 앱 메인 사용률 / 실시간 추천 피드 지표'에 있다. 공개 페이지라 수치는 화면에 넣지 않는다.
- 추천 사유는 메인이 아니라 추천 피드에 보여주는 방향으로 바뀌었다(사용자 2026-11-17).

## 시안 비교 구조

- `?ver=asis | a | b | c | d`(A안 바텀 탭 · B안 추천 카드 · C안 탭 + 카드 · D안 상단 칩 탭), 지정이 없으면 `a`. 시안마다 `main`(asis = 운영 메인 | card = 피드 미리보기 메인 → body[data-main]), `tabbar`(asis | float → body[data-tabbar]), `feed`(tab = 바텀 추천 탭 | push = 밀어 넣기 | top = 메인 상단 추천 탭 → body[data-feed])를 정한다: 현재 asis/asis/push · A asis/float/tab · B card/float/push · C card/float/tab · D asis/float/top. 바텀 탭 2번째는 feed가 tab이면 추천, 나머지는 커뮤니티. 추천 탭 툴팁은 `tip`(→ body[data-tip]) — A안만 켠다. 예전 링크 `?ver=tab`은 `a`로 연다(`?ver=c`는 2026-11-18부터 C안). PC는 폰 위 전환 막대, 모바일은 왼쪽 아래 떠 있는 버튼 → 바텀시트(`compare.js/css`, 위치 동의 비교 프로토타입에서 옮김).
- 시안을 바꾸면 공고뷰를 닫고 메인 맨 위로 돌아간다.
- 시안을 늘릴 때는 `compare.js`의 `VERSIONS`, `index.html`의 `data-ver-pick` 버튼(PC 막대·모바일 시트 둘 다)을 함께 추가하고, 메인 모양은 `VERSIONS[].main` → `body[data-main]`(카드 메인 CSS는 `body[data-main="card"]`), 탭바(asis|float)는 `VERSIONS[].tabbar` → `body[data-tabbar]`, 그 밖의 시안별 차이는 `body[data-ver]`로 나눈다.
- 앞으로 붙일 후보(노션 '시안 방향별 근거'): 헤더 아래 탭(LNB), 피드 공고 미리보기 + 진입 버튼(상단 카드 자리 / 메인 중간), 상단 카드 마지막 장 진입 카드, 퀵메뉴 피드 아이콘.

  - 탭은 `홈`·`실시간 추천 알바` 둘이고, 최근 본·스크랩은 다른 화면으로 가는 바로가기(↗)라 동작하지 않는다.
- 메인(홈 탭): 운영 메인에서 **상단 추천 카드·`더보기`·분홍 배경을 뺐다**. 헤더(흰 바탕) → 칩 줄 → 11 → 퀵메뉴(좌우 20, 줄 12/8 · 8/16, 흰 바탕·모서리 없음) → 필터 → 적극 채용중(회색 #F6F7F8)부터는 운영 메인 그대로. 위치는 Figma와 1px 안쪽으로 맞다.
- **위에 붙지 않는다**(사용자 결정 2026-11-18: 운영 메인은 헤더와 공통 필터가 sticky라 탭까지 붙일 수 없다). 내리면 칩 줄이 함께 올라가 사라진다.
- 추천 탭 = 피드 화면(feed.js)의 필터 칩·카드·새로고침을 복제해 메인 스크롤 안에 넣는다(Figma에 이 상태는 없어 내가 정했다). 피드 TopNavigation(제목·뒤로 가기)은 없다. 헤더·칩 줄은 흰 바탕, 그 아래는 surface.
- 바꾸는 법: 칩 누르기만. 들어오는 패널이 그 방향에서 살짝 밀려 들어온다.
- 스크롤: 칩 줄이 보이면 그 자리 그대로 새 탭을 처음부터, 가려져 있으면 그 탭이 보던 곳(최소 칩 줄이 헤더 밑으로 막 가려지는 곳). `mainTabs.openFeed`(D안에는 메인 `더보기`가 없다) → `topTabs.select('rec', {toTop})`.
- 패널은 display:none 대신 높이 0으로 접는다(가로 스크롤 위치를 지키려고). 홈 패널 `.dp-home`이 메인 내용 전체(B안 미리보기 포함)를 감싼다 — 다른 시안에서는 그냥 감싸기만 한다.
- 바텀 탭은 B안과 같은 떠 있는 유리 탭 바 + 커뮤니티(Figma 시안의 탭 바도 커뮤니티). 툴팁 없음.
- 살필 것(설명 패널에도 적음): 칩 줄이 스크롤로 사라짐, 탭과 바로가기(↗)가 한 줄에 섞임, 상단 카드가 빠져 메인에서 피드 공고 미리보기가 없음, 추천 탭에서 헤더 지역(서울 전체)과 피드 지역 칩(서초구 10km)이 겹침.

## 시안 설명 패널 (PC 전용, 사용자 요청 2026-11-17)

- `guide.css` / `guide.js`, 마크업은 `index.html`의 `<aside id="guide">`. 메인 추천 사유 프로토타입의 정책 패널 구조를 옮겼다. 900px 이상에서만 폰 오른쪽에 보인다.
- 항목: 목적(늘 펼침) · 현재 · A안 · B안 · C안 · D안. 지금 보는 시안(body[data-ver]) 항목을 펼치고 왼쪽에 표시한다.
- 시안마다 무엇 · 왜(근거) · 살필 것. 공개 페이지라 **내부 수치와 Figma 링크는 넣지 않고** 비교 표현으로만 쓴다(수치는 사용자 노션 문서).
- 시안이나 근거가 바뀌면 패널 문구와 머리말 날짜(`pol-meta`)를 같이 고친다.

## 프로젝트 구성

- `index.html`: 메인, 추천 피드, 떠 있는 탭 바, 공고뷰, 시안 전환
- `style.css`: 토큰, 폰 프레임, 반응형
- `home.css` / `home.js`: 운영 메인과 카드, 현재 탭바 스타일. `window.homeScroller`, `window.homeMain`
- `feed.css` / `feed.js`: 추천 피드. `window.recFeed`
- `tabbar.css` / `tabs.js`: 바텀 탭 시안, 메인 ↔ 피드 이동(현재 시안의 밀어 넣기 포함). `window.mainTabs`
- `toptabs.css` / `toptabs.js`: D안 상단 칩 탭(`홈 · 실시간 추천 알바` + 바로가기), D안 메인 모양, 추천 패널(피드 복제). `window.topTabs`
- `jobs.js`: 더미 공고(운영 메인 `buildMain()` · 피드 `buildFeed()`)와 공고뷰 값. `build()`는 실험용 메인 것이라 쓰지 않는다.
- `detail.css` / `detail.js`: 공고뷰
- `app.js`: 화면 밀어서 뒤로 가기(공고뷰만 기록을 쌓는다), 모바일 viewport 높이. `window.mainNav`
- `compare.css` / `compare.js`: 시안 전환
- `guide.css` / `guide.js`: 시안 설명 패널(PC 전용)

## 작업 규칙

- 기존 텍스트와 시안 의미를 요청 없이 바꾸지 않는다.
- 반복되는 색상과 규격은 CSS 변수로 관리한다.
- 에셋은 Figma에서 받은 파일을 그대로 쓴다.
- 사용자는 file://로 연다. CSS mask, fetch처럼 file://에서 막히는 기능은 쓰지 않고, 검수도 file://로 한다.
- GitHub Pages는 파일을 10분간 캐시한다. CSS·JS를 고쳐 배포할 때는 `index.html`의 `?v=` 값을 함께 올린다.
