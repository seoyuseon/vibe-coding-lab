# 프로젝트: 알바몬 구 메인 온보딩 완료 프로토타입

## 적용 범위

- 이 지침은 `albamon-onboarding-oldmain/` 프로젝트에만 적용한다.
- 메인이 신/구로 실험 중이라, 온보딩을 마친 구 메인 그룹이 보는 완료 화면을 따로 만든다(2026-11-16).
- 신 메인 완료 화면은 `albamon-onboarding/`(시안 A~D)에 있다. 코치마크·하이라이트 연출은 거기서 가져왔지만 두 폴더를 함께 고치지 않는다.
- 잡코리아 콘텐츠LAB의 JAMS 2.0 규칙을 자동으로 가져오지 않는다.

## 사용자와 정한 것 (2026-11-16)

- 앞단 온보딩 없이 완료 화면(구 메인)부터 연다. 열면 바로 고른 시안이 재생된다.
- 더미 조건: 지역 `서초구 외 2` · 하는 일 `바리스타 외 2` · 기간 `한 달 이내`. 구 메인 지역 표기는 `~외 n`과 `km`가 섞여 있어 `외 n`으로 정했다.
- 구 메인은 홈에서 공고를 보게 하는 화면이 아니다. 그래서 온보딩 선택값이 적용됐다는 걸 알리려면 지역·필터에 거는 게 맞다고 봤다. 필터 칩은 아래 큐레이션 섹션에 적용된다. 실시간 추천 알바에도 조건이 반영되지만 1뎁스 더 들어가야 확인되는 구조라, 짚어줄지는 비교해 보고 정한다.
- 실시간 추천 알바 카드는 Figma 더미 대신 조건에 맞는 공고(서초구 카페·바리스타 단기)로 채웠다. 아래 큐레이션 섹션(적극 채용중·공고 리스트)은 Figma 그대로다.

## 시안

- 링크 값은 `?v=a1`·`a2`·`b`(지정이 없으면 a1, `a`는 a1로 연다).
- A-1 코치마크 · 필터(Figma): 딤 30% → 1/2 상단 지역(흰 하이라이트 r14, `다음`·`건너뛰기`) → 2/2 필터 칩(흰 박스 x12·w365·h64·r16, `다른 조건은 여기서 바꿀 수 있어요.` · `확인`). 마지막 버튼은 닫기만 한다(피드로 스크롤하지 않음).
- A-2 코치마크 · 추천: 1/2는 A-1과 같다. 2/2는 실시간 추천 카드와 `실시간 추천 알바 더보기` 버튼을 함께 감싼다(투명 하이라이트 r24). 문구 `선택한 조건으로 추천 알바를 골랐어요.` · `확인`은 Figma에 없는 초안이다(사용자 확인).
- B 하이라이트: Figma 토스트 `선택한 조건을 적용했어요`(탭바 위 24px)에, 예전 프로토타입의 반짝임(지역·선택된 필터 칩을 동시에 3번)을 더했다.
- 흰 하이라이트 안의 대상(지역 버튼·필터 칩 행)은 사본을 그려 딤 위에서도 원래 모습으로 보이게 한다.

## Figma와 다르게 둔 것

- 실시간 추천 양옆 카드의 파란 테두리(#d5e4ff)·파란 급여 글자는 잡코리아 토큰이 섞인 것으로 보고 가운데 카드(주황 테두리 50%)와 같게 했다.
- 필터 행은 B 프레임의 예전 칩 대신 A 2/2 프레임의 FilterBar 칩(선택 상태 포함)으로 통일했다.
- 헤더는 A 1/2 기준(`서초구 외 2`)으로 맞췄다. Figma A 2/2·B 헤더는 `서울 전체`였다.

## 프로젝트 구성

- `index.html`: 구 메인 화면, 토스트, 코치마크, 시안 비교 UI
- `style.css`: 토큰, 폰 프레임, 반응형(`albamon-main-recommend/`에서 복사)
- `home.css` / `home.js`: 구 메인, 시안 연출(A-1·A-2·B), 시안 비교 UI, 모바일 viewport
- `jobs.js`: 실시간 추천 알바(9건)·적극 채용중(12건)·공고 리스트(3건) 더미
- `assets/home/`: Figma에서 받은 에셋. `list-chip-back.svg`는 Figma 리스트 칩에 들어 있는 `system-back` 아이콘 그대로다.

## 화면·동작 규칙

- PC는 390×844 휴대폰 프레임, 모바일(`max-width: 520px`)은 화면 전체를 쓰고 목업 상태바를 숨긴다. PC와 모바일을 각각 검수한다.
- 시안 전환·다시 보기: PC는 폰 위 바, 모바일은 좌하단 런처 → 시트. 코치마크가 떠 있는 동안 모바일 런처는 숨긴다(말풍선을 가림).
- 웹폰트(CDN) 때문에 load가 늦을 수 있어, 폰트를 최대 0.8초만 기다렸다가 시작하고 폰트·이미지가 늦게 들어오면 코치마크 위치를 다시 맞춘다.
- 실시간 추천 캐러셀은 두 번째 카드가 가운데 오도록 시작한다(가로로 넘김, 스냅).
- 버튼·카드·탭은 동작하지 않는다(완료 연출 비교용).

## 작업 규칙

- 기존 텍스트와 시안 의미를 요청 없이 바꾸지 않는다.
- 반복되는 색상과 규격은 CSS 변수로 관리한다.
- 에셋은 Figma에서 받은 파일을 그대로 쓴다.
- 사용자는 file://로 연다. CSS mask, fetch처럼 file://에서 막히는 기능은 쓰지 않고, 검수도 file://로 한다.
- GitHub Pages는 파일을 10분간 캐시한다. CSS·JS를 고쳐 배포할 때는 `index.html`의 `?v=` 값을 함께 올린다.
