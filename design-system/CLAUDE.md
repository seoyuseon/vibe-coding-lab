# 프로젝트: JAMS 디자인 시스템 자료

## 적용 범위

- 이 지침은 `design-system/`의 가이드와 분석 문서에만 적용한다.
- 이 폴더는 여러 잡코리아 프로젝트가 참조하는 공용 디자인 시스템 자료다.

## 기준 자료

- 현재 저장소의 기준은 JAMS 2.0이다.
- Figma: https://www.figma.com/design/Dojrcqpr6br5B6BNkj08jR/JAMS-2.0
- fileKey: `Dojrcqpr6br5B6BNkj08jR`
- 핵심 가이드: `JAMS-2.0-GUIDE.md`
- 갭 분석: `gap-analysis-report.md`
- 공용 역할 문서: `../.claude/agents/`

## 작업 규칙

- 여러 프로젝트가 참조하므로 기존 토큰명이나 정의를 요청 없이 제거하거나 바꾸지 않는다.
- Figma에서 확인한 값과 저장소에 기록된 값을 구분한다.
- 디자인 시스템 버전을 변경할 때는 적용 대상 프로젝트와 마이그레이션 범위를 명시한다.
- 문서의 상대경로와 Figma 링크가 유효한지 확인한다.
- 변경 이유와 영향을 받는 프로젝트를 기록한다.
