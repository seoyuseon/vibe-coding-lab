# 프로젝트: 알바몬 알바지도

## 적용 범위

- 이 지침은 `albamon-alba-map/` 프로젝트에만 적용한다.
- 잡코리아 콘텐츠LAB의 JAMS 2.0 규칙을 자동으로 가져오지 않는다.

## 프로젝트 구성

- `index.html`: 화면 구조와 프로토타입 상호작용
- `style.css`: 토큰, 화면 스타일, 반응형 처리
- `assets/`: 지도 이미지, 핀, 카테고리 및 내비게이션 아이콘
- 순수 HTML/CSS/JavaScript로 구현한다.
- 기본 폰트는 Pretendard다.

## 화면 기준

- PC와 모바일은 서로 다른 사용 환경이며 각각 별도로 확인한다.
- PC에서는 390×800 디자인을 휴대폰 프레임 형태로 보여준다.
- 모바일(`max-width: 520px`)에서는 프레임을 제거하고 실제 앱처럼 화면 전체를 사용한다.
- 모바일은 390px 디자인 폭을 기기 너비에 맞춰 스케일하고, `visualViewport` 높이를 반영해 지도가 화면을 채우도록 한다.
- 한 화면의 수정 결과가 다른 화면에서도 올바른지 자동으로 가정하지 말고 PC와 모바일을 각각 검수한다.
- 모바일에서는 고정 화면, safe area, 주소창에 따른 viewport 변화, 바텀 UI 가림을 확인한다.

## 시안과 상호작용

- 시안 A: 현재 운영
- 시안 B: 현재 운영 + 최신 등록 핀 배지
- 시안 C: 지도 위 요소 디벨롭
- 기본 시안은 C다.
- 시안 C에서는 지도 영역을 탭하면 검색창과 하단 UI가 비켜나는 지도 몰입 모드가 동작한다.
- 검색창, 칩, 탭바 등 UI 조작은 지도 몰입 모드를 잘못 토글하지 않아야 한다.

## 작업 규칙

- 기존 텍스트, URL, 시안 의미를 요청 없이 변경하지 않는다.
- 반복되는 색상과 규격은 CSS 변수로 관리한다.
- 기존 SVG와 지도 에셋을 우선 재사용한다.
- 한 번에 한 영역씩 수정하고 PC·모바일 및 시안 A·B·C에 미치는 영향을 확인한다.
- 애니메이션에는 `prefers-reduced-motion` 대응을 유지한다.
- 모바일 앱처럼 확인하는 동작을 깨뜨리는 페이지 스크롤이나 레터박스를 만들지 않는다.

## 권장 검수 크기

- PC: 1440×1000 이상
- 모바일: 390×844 및 375×812
- 520px 경계의 전후 너비에서 레이아웃 전환을 확인한다.
